# Screens Spec

## 개요

냉털마스터 주요 화면 스펙 정의.
4개 핵심 화면의 레이아웃, 컴포넌트 구성, 상호작용을 명시한다.

---

## 화면 목록

1. **홈 (Home)** - 랜딩 페이지
2. **레시피 목록 (Recipe List)** - 추천 레시피 목록
3. **레시피 상세 (Recipe Detail)** - 레시피 상세 정보
4. **재료 추가 (Add Ingredient)** - 재료 입력 화면

---

## 1. 홈 (Home)

### 경로
- `/` (인증 전)
- `/dashboard` (인증 후, 메인 대시보드)

### 레이아웃

#### 인증 전 (`/`)
```
┌─────────────────────────────────┐
│  [로고] 냉털마스터                │
│                                   │
│  "남는 재료만 넣으세요,           │
│   최고의 레시피를 찾아드립니다"   │
│                                   │
│  [로그인]  [회원가입]             │
│                                   │
│  [주요 기능 소개]                 │
│  - 스마트 재료 인식               │
│  - 맞춤 레시피 추천               │
│  - 유통기한 관리                  │
└─────────────────────────────────┘
```

#### 인증 후 (`/dashboard`)
```
┌─────────────────────────────────┐
│  [헤더: 로고, 네비, 사용자]      │
├─────────────────────────────────┤
│  내 재료                         │
│  ┌───────────────────────────┐  │
│  │ [재료 입력창] [추가]       │  │
│  │ [태그 목록]                │  │
│  └───────────────────────────┘  │
├─────────────────────────────────┤
│  추천 레시피                     │
│  ┌──────┐ ┌──────┐ ┌──────┐    │
│  │레시피│ │레시피│ │레시피│    │
│  │ 카드 │ │ 카드 │ │ 카드 │    │
│  └──────┘ └──────┘ └──────┘    │
└─────────────────────────────────┘
```

### 컴포넌트
- `HomeView.vue` (인증 전)
- `DashboardView.vue` (인증 후)
- `AppHeader.vue`
- `IngredientInput.vue`
- `RecipeCard.vue` (n개)

### 상호작용
- 재료 입력 → 실시간 레시피 추천 API 호출
- 레시피 카드 클릭 → 레시피 상세 페이지 이동

## 2. 레시피 목록 (Recipe List)

### 경로
- `/recipes`
- `/recipes?tier=1` (Tier 필터)
- `/recipes?category=한식` (카테고리 필터)

### 레이아웃
```
┌─────────────────────────────────┐
│  [헤더]                         │
├─────────────────────────────────┤
│  레시피 추천                     │
│  [Tier 필터] [카테고리 필터]     │
├─────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐    │
│  │Tier 1│ │Tier 1│ │Tier 2│    │
│  │레시피│ │레시피│ │레시피│    │
│  │ 카드 │ │ 카드 │ │ 카드 │    │
│  └──────┘ └──────┘ └──────┘    │
│  ┌──────┐ ┌──────┐              │
│  │Tier 2│ │Tier 3│              │
│  │레시피│ │레시피│              │
│  │ 카드 │ │ 카드 │              │
│  └──────┘ └──────┘              │
└─────────────────────────────────┘
```

### 컴포넌트
- `RecipeListView.vue`
- `RecipeCard.vue` (n개)
- `FilterBar.vue` (Tier, 카테고리 필터)

### 데이터
- Tier별 그룹화 표시
- Tier 1 (100% 매칭) 최상단
- Tier 2 (주재료 매칭) 중간
- Tier 3 (부분 매칭) 하단

### 상호작용
- 필터 변경 → API 재호출
- 카드 클릭 → 레시피 상세 이동
- 북마크 버튼 → 레시피 저장

### 경로
- `/recipes/:id`

### 레이아웃
```
┌─────────────────────────────────┐
│  [헤더] [← 뒤로]                │
├─────────────────────────────────┤
│  [썸네일 이미지]                 │
│  ─────────────────────────────  │
│  김치볶음밥                      │
│  재료 일치율: ████████░ 85%     │
│                                   │
│  ✅ 보유 재료                    │
│  • 밥                             │
│  • 계란                           │
│                                   │
│  ❌ 부족한 재료                   │
│  • 김치                           │
│                                   │
│  [레시피 보기 ↗] [★ 저장]        │
│                                   │
│  [유튜브 링크] [블로그 링크]      │
└─────────────────────────────────┘
```

### 컴포넌트
- `RecipeDetailView.vue`
- `RecipeHeader.vue` (썸네일, 제목)
- `IngredientList.vue` (보유/부족 재료)
- `ActionButtons.vue` (링크, 북마크)

### 데이터
- 레시피 상세 정보
- 보유 재료 매칭 정보
- 부족한 재료 목록
- 외부 링크 (YouTube, 블로그)

### 상호작용
- 뒤로 버튼 → 이전 페이지
- 외부 링크 → 새 탭에서 열기
- 북마크 → 레시피 저장/해제

## 4. 재료 추가 (Add Ingredient)

### 경로
- `/ingredients/add`
- `/ingredients/add?source=manual` (수동 입력)
- `/ingredients/add?source=receipt` (영수증 OCR)
- `/ingredients/add?source=vision` (냉장고 사진)

### 레이아웃
```
┌─────────────────────────────────┐
│  [헤더] [← 뒤로]                │
├─────────────────────────────────┤
│  재료 추가                       │
│                                   │
│  입력 방법 선택                   │
│  ┌────────┐ ┌────────┐          │
│  │ 수동    │ │ 영수증 │          │
│  │ 입력    │ │ 촬영   │          │
│  └────────┘ └────────┘       │
│  ┌────────┐                     │
│  │ 냉장고 │                     │
│  │ 사진   │                     │
│  └────────┘                     │
│                                   │
│  [수동 입력 선택 시]              │
│  ┌───────────────────────────┐   │
│  │ 재료명: [입력창]          │   │
│  │ 카테고리: [선택]          │   │
│  │ 수량: [입력]              │   │
│  │ 유통기한: [날짜 선택]     │   │
│  │ [추가]                    │   │
│  └───────────────────────────┘   │
└─────────────────────────────────┘
```

### 컴포넌트
- `AddIngredientView.vue`
- `SourceSelector.vue` (입력 방법 선택)
- `ManualInputForm.vue` (수동 입력 폼)
- `ReceiptUpload.vue` (영수증 업로드)
- `VisionUpload.vue` (사진 업로드)

### 입력 방법
1. **수동 입력**: 재료명, 카테고리, 수량, 유통기한 직접 입력
2. **영수증 OCR**: 영수증 사진 업로드 → AI 분석 → 재료 추출
3. **냉장고 사진**: 냉장고 사진 업로드 → AI 객체 탐지 → 재료 추출

### 상호작용
- 입력 방법 선택 → 해당 폼 표시
- 영수증/사진 업로드 → VisionJob 생성 → 결과 폴링
- 재료 추가 완료 → 냉장고 목록으로 이동

## 공통 레이아웃

### AppLayout
- 모든 인증 후 화면의 공통 레이아웃
- `AppHeader` 포함
- 콘텐츠 영역: 최대 너비 1200px, 중앙 정렬

### AppHeader
- 로고 (왼쪽)
- 네비게이션 (중앙): 대시보드, 레시피, 요리책
- 사용자 메뉴 (오른쪽): 닉네임, 로그아웃

---

## 반응형 디자인

### 모바일 (< 768px)
- 1열 레이아웃
- 카드 전체 너비
- 햄버거 메뉴

### 태블릿 (768px ~ 1024px)
- 2열 그리드
- 사이드바 접기 가능

### 데스크톱 (> 1024px)
- 3열 그리드
- 전체 네비게이션 표시

---

## 제약 조건

- 모든 화면은 모바일 퍼스트
- 최소 터치 영역: 44x44px
- 로딩 상태 표시 필수
- 에러 상태 처리 필수
